# Biomedical Data Analysis in R

A statistical analysis project applying regression and model evaluation techniques to a biomedical dataset using R.

## Project Overview

This project analyzed the `prostate` dataset from the R `faraway` package. The dataset contains clinical and biological measurements related to prostate cancer.

The objective was to explore relationships between variables and apply statistical modeling approaches to analyze prostate-specific antigen levels (`lpsa`).

## Analysis

As part of the project, our group:

- Performed exploratory data analysis and visualization
- Split the dataset into training and test sets
- Applied simple and multiple linear regression
- Examined relationships between clinical variables and the response variable
- Evaluated linear regression assumptions using diagnostic plots
- Performed variable and model selection
- Compared alternative statistical models
- Evaluated model performance on unseen test data
